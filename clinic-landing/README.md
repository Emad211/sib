# لندینگ درمانگاه — پیگیری دیابت و فشار خون

صفحهٔ معرفی درمانگاه با انیمیشن سه‌بعدی روایت‌دار («داستان آقای رضا») و فرم ثبت شماره.

## اجرا

```bash
npm install
npm run dev        # توسعه: http://localhost:5173
npm run build      # خروجی نهایی در dist/ — همین پوشه را روی هاست بگذارید
```

## ساختار

| مسیر | کار |
|---|---|
| `index.html` | محتوای صفحه |
| `src/config.ts` | **نام درمانگاه، تلفن، آدرس API فرم** — قبل از انتشار پر کنید |
| `src/lib/lead.ts` | فرم شماره (اعداد فارسی، ‎+98، اعتبارسنجی) |
| `src/story/narration.json` | **متن روایت هر صحنه و گوینده** |
| `src/story/scenes/*.ts` | هر صحنهٔ انیمیشن؛ حرکت‌ها به کلمه‌های روایت قفل‌اند (`T.at("کلمه")`) |
| `src/story/world.ts` | دنیای سه‌بعدی: حلقه، ایستگاه‌ها، درمانگاه، درخت‌ها |
| `src/story/kit/` | شخصیت‌ها، اشیا، رنگ‌ها |
| `src/story/player.ts`, `audio.ts` | پخش‌کننده، زیرنویس، هماهنگی صدا (Web Audio) |
| `scripts/` | ساخت صدا با ElevenLabs (فقط هنگام build، کلید هرگز به مرورگر نمی‌رسد) |

## تغییر متن یا صدای روایت

1. کلید ElevenLabs در فایل `.env.local` است (`ELEVENLABS_API_KEY=...`). این فایل نباید در گیت یا هاست قرار بگیرد.
2. متن را در `src/story/narration.json` عوض کنید.
3. اجرا کنید:

```bash
npm run voice
```

صدا (`public/story/narration-<هش>.mp3`) و زمان‌بندی کلمه‌به‌کلمه (`src/story/timing.json`) دوباره ساخته می‌شوند و انیمیشن خودکار با آن هماهنگ می‌شود.
نام فایل صدا هش دارد تا بازدیدکننده هرگز نسخهٔ قدیمی را از کش نشنود. بعد از ساخت، صدا خودکار دوباره به متن تبدیل می‌شود و واژه‌هایی که درست تلفظ نشده‌اند فهرست می‌شوند
(عددها ممکن است به‌صورت رقم شنیده شوند و خطا نیستند).
اگر کلمه‌ای که صحنه‌ای به آن قفل است را حذف کنید، در کنسول هشدار می‌گیرید؛ همان کلمه را در فایل صحنه عوض کنید.

- گوینده: Roya (زن، تهرانی، روایتگر) از کتابخانهٔ ElevenLabs. گوینده‌ی دیگر: `npm run voice -- --voice <voiceId>` یا تغییر `voice.id` در narration.json
- نمونه‌صدای گوینده‌های فارسی برای مقایسه (با بازشنوی خودکار): `npm run voice:samples` (خروجی در `voice-samples/`)
- مکث بین صحنه‌ها و سکوت ابتدا/انتها: ثابت‌های بالای `scripts/build-voice.mjs`
- افکت‌های صوتی و موسیقی زمینه: `npm run sfx` (فقط فایل‌های ناموجود ساخته می‌شوند؛ `-- --force music` برای ساخت دوباره)
- لوگوی سه‌بعدی هیرو: اگر `public/logo3d.svg` عوض شد، `npm run bake:logo` را اجرا کنید

## کارایی

- صفحه بدون انیمیشن: حدود ۲۵ کیلوبایت (gzip، شامل CSS).
- هیروی سه‌بعدی بلافاصله بعد از بارگذاری صفحه شروع می‌شود؛ هندسهٔ لوگو از قبل پخته شده (`public/hero-logo.bin`، حدود ۷۰ کیلوبایت) و مرورگر دیگر SVG را پردازش نمی‌کند.
- three.js و صحنه‌ها و فایل‌های صدا (حدود ۱٫۲ مگابایت) فقط وقتی کاربر به بخش انیمیشن نزدیک شد بارگذاری می‌شوند.
- رزولوشن رندر روی دستگاه‌های کند خودکار پایین می‌آید؛ بیرون از دید، رندر متوقف می‌شود ولی صدا ادامه دارد و یک پخش‌کنندهٔ کوچک شناور ظاهر می‌شود.
- اگر مرورگر WebGL نداشته باشد، صدا و زیرنویس بدون تصویر سه‌بعدی پخش می‌شوند.
