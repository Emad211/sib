## ۱. تصمیم‌های قطعی (بخش «ثبت‌شده»)

1. پایش ۲۴/۷ نیست؛ نتیجه روز بعد بررسی می‌شود و برنامه اورژانسی نیست.
2. حسابداری: HTTPS با گواهی معتبر، `PRODUCTION=1`، فقط برای دو نفر (مدیر و رئیس).
3. دامنه: همان `clinic-sib.ir` که DNS آن روی Cloudflare است. یک زیردامنه با ابر خاکستری (فقط DNS، بدون پروکسی) به IP رله اشاره می‌کند. گواهی با DNS-01 از راه API کلودفلر روی PC درمانگاه گرفته می‌شود. نیازی به دامنه یا DNS تازه نیست.
4. هویت بیمار: کد ملی (یا شمارهٔ فراگیر/گذرنامه) و موبایل برای ثبت جدید اجباری است (کد این را اعمال می‌کند). پرونده‌های قدیمی هنگام برگشت بیمار اصلاح می‌شوند.
5. میزبان رله: بهترین (نه ارزان‌ترین) از نظر دسترسی از اپراتورهای موبایل. انتخاب پس از گزارش `m1-r3-best-host` و آزمون تجربی روی دو سیم‌کارت.

## ۷. سؤال‌هایی که از مالک لازم است

1. عکس رسید در ک/د/ض/خرابی: اجباری یا اختیاری؟ (A5)
2. تغییر حقوق پایه (B2) را می‌پذیری؟ بعد از گولدن گیت اعداد قبل/بعد را نشانت می‌دهم.
3. «درآمد» نهایی کدام است؟ (B3) قاعدهٔ فعلی: ویزیت + پرستاری + کار عملی فاکتورهای بسته، بدون مصرفی؛ ولی داشبورد قیمت ناخالص (با سهم بیمه) را جمع می‌زند.
4. حسابداری با گواهی کلاینت (mTLS) یا VPN روی گوشی؟ پیشنهادم mTLS.
5. کد کالای ۶۹ قلم را کی وارد می‌کنی؟ A1 بدون آن به‌طور کامل قابل‌اجرا نیست.
