# واژه‌نامه

> نسخه 1.0 · ۱۴۰۵/۰۸/۰۴

| واژه | معنی در این پروژه |
|---|---|
| حسابداری / Hesabdari | برنامهٔ محلی فعلی درمانگاه (Flask، پورت 8080، فایل `HesabdariSib.exe`، دیتابیس `clinic_new.db`) |
| اپ شیفت | اپ جدید کارکنان: تحویل شیفت، رویدادها، انبار، خرید، پاداش |
| هستهٔ آنلاین | سرور آیندهٔ درمانگاه روی اینترنت (پورتال بیمار، کارت مدیر روی گوشی) |
| فاکتور (invoice) | پروندهٔ مالی یک مراجعه؛ `open` یا `closed`. فاکتور بسته قابل حذف آیتم نیست |
| آیتم فاکتور | یکی از: ویزیت، تزریق (خدمت پرستاری)، کار عملی، مصرفی |
| مصرفی (consumable) | در حسابداری = دارو و مصرفی که به بیمار فروخته می‌شود (مثل لیدوکایین، آپوتل). ۸۵ تعرفه دارد |
| خدمت پرستاری (injection) | تزریق، وصل سرم، تست قند، کنترل فشار و … (۴۵ نوع در پروداکشن) |
| `work_date` | تاریخ کاری شیفت (شیفت شب پس از نیمه‌شب هم به همان تاریخ تعلق دارد) |
| شیفت | `morning` / `evening` / `night` |
| بلوک | چند شیفت پشت‌سرهم با یک نفر، که یک شیفت حساب می‌شود (سند منطق) |
| شمارش کور | کارمند می‌شمارد بی‌آنکه عدد مرجع را ببیند |
| عدد مرجع (E، N) | عددی که سیستم انتظار دارد روی قفسه (E) یا در صندوق (N) باشد |
| مغایرت | اختلاف شمارش نهایی با عدد مرجع |
| کارت روزانه | خلاصهٔ تصمیم‌خواه مدیر، هر روز ساعت ۷:۳۰ |
| تست مشخصه‌نگاری | تستی که رفتار **فعلی** را ثبت می‌کند، حتی اگر عجیب باشد، تا تغییرات آن را بی‌صدا عوض نکنند |
| گولدن مستر | خروجی کامل عددی گزارش‌ها روی یک دیتابیس ثابت؛ هر اختلاف بعدی = هشدار |
| کپی پروداکشن | `_data/prod_snapshot/clinic_new_2026-09-24.db`؛ فقط محلی و فقط‌خواندنی |
| دیتابیس مصنوعی | دیتابیس ساختگی واقع‌نما برای CI، بدون هیچ ردیف واقعی |
| مهاجرت (migration) | تغییر نسخه‌دار schema، فقط افزایشی (ADR-002) |
| ADR | ثبت یک تصمیم معماری (03_DECISIONS) |
| دروازه (gate) | شرط‌های عبور از یک فاز به فاز بعد (02_ROADMAP) |
| PHI | اطلاعات سلامت قابل شناسایی بیمار: نام، کد ملی، موبایل، خدمات |
